# LeadOS Arbeitsstand

Statische Statusseite zum Pilotprojekt **LeadOS** (Hanseatisches Institut): ein digitales Führungswerkzeug für die Aufgabenübergabe zwischen Inhaber und Mitarbeiter.

Die Seite zeigt den aktuellen Projektstand (Phasenleiste "Wo wir stehen") und verlinkt den klickbaren Prototyp: <https://leados-design-foundation.lovable.app>

## Inhalt

| Datei | Zweck |
|---|---|
| `index.html` | Die komplette Seite (HTML, CSS und Inhalt in einer Datei, keine Build-Schritte) |
| `LICENSE` | MIT-Lizenz |

## Ansehen

`index.html` im Browser öffnen. Die Seite lädt nur die Schriften von Google Fonts nach.

## Aktualisieren

Stand und Phasen stehen direkt in `index.html`. Nach einer Änderung auch den Zeitstempel "Stand: …" im Kopfbereich anpassen.
